
# 🐾 Pet Shop Eriwa

## Sobre o projeto

O Pet Shop Eriwa é um sistema web desenvolvido para auxiliar no gerenciamento de um pet shop, facilitando o cadastro de clientes, animais e agendamentos de serviços.

## Objetivo

Organizar as informações dos clientes e seus animais, além de facilitar o controle dos atendimentos de banho e tosa.

## Funcionalidades

- Cadastro de clientes.
- Edição e exclusão de clientes.
- Cadastro de animais.
- Associação dos animais aos seus tutores.
- Edição e exclusão de animais.
- Agendamento de banho e tosa.
- Cancelamento de agendamentos.
- Consulta dos registros.
- Indicadores de clientes, pets e atendimentos.
- Armazenamento local dos dados utilizando localStorage.

## Armazenamento de dados

O sistema utiliza o localStorage do navegador para armazenar os registros localmente. Os dados permanecem disponíveis no mesmo navegador e dispositivo, mesmo após atualizar ou fechar a página.
